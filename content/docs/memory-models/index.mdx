Memory is what turns a one-off harness session into a persistent [familiar](/docs/familiars/what-is-a-familiar). Models are the provider side of that familiar's reasoning, but Coven does not become a model gateway. The durable runtime boundary is: Coven records sessions and events; clients/familiars derive memory from those events; harnesses own provider auth and model access.
