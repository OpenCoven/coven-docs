**Coven** is not a harness. It is the local runtime substrate that harnesses run on.

Whether you are using OpenClaw, Codex, Claude Code, a custom tool loop, or something else entirely — Coven provides the persistent layer underneath: named familiars with memory, identity, and tooling that survive across sessions. Harnesses bring their own credentials, models, and provider accounts. Coven brings the boundary, the record, and the continuity.

_Familiars_ are the agents that live inside Coven — persistent, named, and yours.

```sh
# Your familiar's work, recorded and replayable
coven run codex "remind me what changed since the last release" --title "Release recap"
coven sessions        # browse, rejoin, or replay the run
coven attach <id>     # watch it live, or replay it later
```

Familiars build on that substrate: every session a familiar runs is recorded, replayable, and feeds the [memory layers](/docs/memory-models/memory) that make the familiar persistent. See [What is a familiar?](/docs/familiars/what-is-a-familiar) for the full picture.
