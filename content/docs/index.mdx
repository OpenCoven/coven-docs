Coven runs coding agents inside a local, project-scoped boundary. It keeps the parts a harness does not: session lifecycle, an append-only record, replay, and a stable local API.

## Why Coven

- **Use the harness you trust.** Run Codex, Claude Code, Copilot CLI, Coven Code, or a registered adapter without moving provider credentials into Coven.
- **Keep work inside the project.** The daemon canonicalizes project roots and working directories before a session starts.
- **Keep the record.** Sessions, events, and logs remain available after a harness exits, so work can be inspected, replayed, archived, or removed deliberately.
- **Keep control local.** One same-user daemon owns PTYs and exposes a versioned HTTP-over-Unix-socket API for the CLI and your own local clients.
