# Welcome to Coven

**Coven** is a framework for building AI agents — called _familiars_ — that persist across sessions, carry memory and personality, and live wherever your work lives.

## What Makes Coven Different?

- **Persistent familiars** — agents with memory, personality, and continuity across sessions
- **Tool access** — web, exec, files, messaging, calendar, and more
- **Multi-channel** — Telegram, Discord, iMessage, WhatsApp, and custom channels
- **Observable** — every action traced, inspectable, and auditable
- **Open** — self-hosted, extensible, yours

```typescript
// Your familiar, your workspace
const familiar = await coven.spawn({
  name: 'Nova',
  personality: 'warm, direct, practical',
  tools: ['exec', 'web_search', 'memory'],
});

await familiar.chat('Remind me about the deployment at 3pm.');
```
