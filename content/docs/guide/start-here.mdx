You do not need to learn every OpenCoven project first. Choose the outcome you
want, then follow the owning project's current setup instructions.

## Use a familiar

For a focused conversation, start with [Coven Chat](https://github.com/OpenCoven/chat).
It connects to the Coven CLI on your computer; installing an app does not replace
provider setup. For a broader desktop control room, start with
[Coven Cave](https://github.com/OpenCoven/coven-cave#install).

**Your next action:** check that app's supported platform and installation path,
then complete its local setup. Source availability, a preview, and a downloadable
release are different things. Follow the current README and release notes rather
than assuming every platform has the same capabilities.

Want notes, tasks, tools, and terminals in one workspace instead? See
[Open Sesame](https://github.com/OpenCoven/open-sesame). Its native host is macOS;
the browser preview does not grant local machine access. It is an alternative
workspace, not a prerequisite for Chat or the CLI.

## Build with Coven

Start with the [first recorded session](/docs/guide/getting-started): install the
CLI, connect one provider, run a bounded task, and inspect the record. The
[first-value walkthrough](/docs/guide/first-value) explains what to verify before
trying another surface.

**Your next action:** install Coven and run `coven doctor`. Check
[Platforms](/docs/guide/platforms) first for OS and architecture limits.
After one working session, use the [Local API](/docs/reference/api) if you are
building a client. The daemon remains the authority boundary; a UI is not one.

## Contribute

Choose the repository you use and read its `CONTRIBUTING.md` and, for an agent,
its `AGENTS.md`. Check existing issues and pull requests before starting.

**Your next action:** try Coven's credential-free
[Contributor First 10 Minutes](https://github.com/OpenCoven/coven/blob/main/CONTRIBUTING.md#contributor-first-10-minutes),
or find a scoped
[good first issue](https://github.com/search?q=org%3AOpenCoven+label%3A%22good+first+issue%22+state%3Aopen&type=issues).
That smoke path uses a fake harness; it is not evidence of a real provider run.

Need help choosing? Use [Support](/docs/reference/support). Report vulnerabilities
privately under the owning repository's security policy, not in a public issue.

## How the pieces fit

The [ecosystem map](/docs/guide/ecosystem) explains ownership. It is a reference,
not a required reading list. Start with one successful task before adding more
tools, orchestration, remote hosts, or automation.
