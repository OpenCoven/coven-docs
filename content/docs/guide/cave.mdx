**Cave** is OpenCoven's native desktop and mobile home. It is the place where your familiars live and where you go to be with them — to talk, watch what they're doing, and follow their work across sessions.

A [familiar](/docs/familiars/what-is-a-familiar) is not a chat window. It has a name, a purpose, a memory, a toolset, and a place in your day. Cave is the surface that makes that visible.

Cave is local-first. It talks to the `coven` daemon on your machine over a Unix socket at `~/.coven/coven.sock`. There is no cloud, no upstream, no remote authority.

Because Cave runs as a native app rather than a browser tab, it can do things a web page can't: spawn local terminal and browser panes, drive local agent sessions through a sidecar, persist state offline, and hand a live session off to your phone over Tailscale.

## Stack

| Layer | Tech |
|-------|------|
| Native shell | Tauri 2 (macOS / Windows / Linux) — window and updater, pty terminal, browser pane, speech, sidecar archive |
| Frontend | Next.js 16 (App Router) + React 19 + TypeScript |
| Styles | Tailwind v4 |
| Native mobile | SwiftUI iOS client (`apps/ios/CovenCave`) |
| Mobile handoff | Tailscale |
| Terminal | xterm.js |
| IPC | Unix socket → `~/.coven/coven.sock` |

## Install

On macOS, install from the OpenCoven Homebrew tap — the cask ships the same signed and notarized DMG as the release pipeline:

```bash
brew install --cask opencoven/tap/coven-cave
```

Direct macOS, Windows, and Linux builds (plus update metadata and checksums) are on the [releases page](https://github.com/OpenCoven/coven-cave/releases/latest). The iOS client ships through TestFlight.

To run from source instead:

```bash
git clone https://github.com/OpenCoven/coven-cave.git
cd coven-cave
pnpm install
pnpm tauri dev   # native window
# or
pnpm dev         # browser-only at http://localhost:3000
```

You will need the `coven` daemon running locally — see [Install Coven](/docs/guide/install).
