## Go deeper

- For daemon restart and orphaned sessions, read [Daemon lifecycle](/docs/daemon/lifecycle). Restoring an archived record does not rerun its work.
- For scripted launches and structured output, use [Run](/docs/cli/run) and [Sessions](/docs/cli/sessions).
- For provider and model controls in the interactive UI, read [Coven Code](/docs/coven-code), a preview surface.
- For endpoint schemas and examples, use the generated [API Reference](/docs/openapi).
- Before operating across hosts, read [Daemon security](/docs/daemon/security) for the local IPC and transport boundaries.
- To contribute a documentation change, follow the [contributing guide](https://github.com/OpenCoven/coven-docs/blob/main/CONTRIBUTING.md) in the [coven-docs repository](https://github.com/OpenCoven/coven-docs).
