# Sessions

## Create a Session

```http
POST /v1/sessions
Content-Type: application/json

{
  "familiar_id": "fam_nova",
  "channel": "api",
  "context": {}
}
```

```json
{
  "id": "sess_abc123",
  "familiar_id": "fam_nova",
  "status": "active",
  "created_at": "2026-05-17T00:00:00Z"
}
```

## Send a Message

```http
POST /v1/sessions/:id/messages
Content-Type: application/json

{
  "role": "user",
  "content": "What's on my calendar today?"
}
```

## List Messages

```http
GET /v1/sessions/:id/messages
```

## Close a Session

```http
DELETE /v1/sessions/:id
```
