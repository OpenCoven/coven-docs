# Harnesses

A **harness** is an AI provider adapter that powers one or more familiars. Coven supports multiple harness types: `openclaw`, `claude_code`, `codex`, `hermes`, and custom adapters.

Each familiar is bound to exactly one harness. You can migrate a familiar between harnesses at any time.

## List harnesses

```http
GET /v1/harnesses
```

```json
{
  "harnesses": [
    {
      "id": "harness_openclaw",
      "name": "OpenClaw",
      "kind": "openclaw",
      "status": "healthy",
      "familiar_count": 3,
      "created_at": "2026-05-01T00:00:00Z"
    },
    {
      "id": "harness_claude_code",
      "name": "Claude Code",
      "kind": "claude_code",
      "status": "healthy",
      "familiar_count": 1,
      "created_at": "2026-05-10T00:00:00Z"
    }
  ]
}
```

## Get a harness

```http
GET /v1/harnesses/:id
```

```json
{
  "id": "harness_openclaw",
  "name": "OpenClaw",
  "kind": "openclaw",
  "status": "healthy",
  "config": {
    "gateway_url": "wss://...",
    "model_primary": "openai/gpt-5.5",
    "model_fallbacks": ["openai/gpt-5.4-mini"]
  },
  "familiar_count": 3,
  "familiars": ["fam_nova", "fam_sage", "fam_echo"]
}
```

## Register a harness

```http
POST /v1/harnesses
Content-Type: application/json

{
  "name": "My Codex",
  "kind": "codex",
  "config": {
    "api_key": "sk-...",
    "model_primary": "openai/gpt-5.5"
  }
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | ✓ | Display name |
| `kind` | string | ✓ | `openclaw` \| `claude_code` \| `codex` \| `hermes` \| `custom` |
| `config` | object | ✓ | Harness-specific configuration |

## Update a harness

```http
PATCH /v1/harnesses/:id
Content-Type: application/json

{
  "config": {
    "model_primary": "anthropic/claude-sonnet-4-5",
    "model_fallbacks": ["anthropic/claude-haiku-3.5"]
  }
}
```

## Harness health check

```http
GET /v1/harnesses/:id/health
```

```json
{
  "id": "harness_openclaw",
  "status": "healthy",
  "latency_ms": 42,
  "last_check": "2026-05-17T20:00:00Z"
}
```

## List familiars on a harness

```http
GET /v1/harnesses/:id/familiars
```

## Deregister a harness

```http
DELETE /v1/harnesses/:id
```

> Familiars bound to this harness must be migrated first. Returns `409` if active familiars exist.

## Harness kinds

| Kind | Description |
|------|-------------|
| `openclaw` | OpenClaw gateway (default, recommended) |
| `claude_code` | Anthropic Claude Code interactive PTY |
| `codex` | OpenAI Codex CLI |
| `hermes` | Hermes local runner |
| `custom` | Custom adapter via OpenCoven SDK |
