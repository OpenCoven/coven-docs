# Future Hosted API

This section is hidden from the main docs navigation because it describes future hosted API direction, not the current Coven runtime contract.

For current client integrations, use [Coven Local API](/docs/reference/api): HTTP over the local Unix socket at `<covenHome>/coven.sock`, versioned under `/api/v1`, with no OAuth, JWT, bearer-token, API-key, or browser-cookie auth in v0.

Do not use the examples below as shipped API behavior until a hosted API design exists.

## Future Authentication Direction

Hosted access will need an explicit auth and pairing design before it is documented as current behavior.

```http
Authorization: Bearer <your-api-key>
```

API-key examples are placeholders for future hosted service work.

## Conventions

- All responses are JSON
- Timestamps are ISO 8601 UTC
- Errors return `{ "error": { "code": string, "message": string } }`
