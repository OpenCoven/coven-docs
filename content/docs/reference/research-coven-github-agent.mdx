## Abstract

The brief investigates a Coven-native GitHub App coding agent: a thin GitHub integration that handles webhook intake, installation-token authentication, Check Runs, issue and PR lifecycle, and task status, while delegating actual coding work to the CastCodes execution backend.

The research compares incumbent agent products and open-source systems, studies GitHub App mechanics, and recommends a product direction centered on OpenCoven's differentiators:

- persistent familiar identity
- bring-your-own-model configuration
- composable skills
- cross-session memory
- multi-familiar routing
- Cave as the owned oversight UI
