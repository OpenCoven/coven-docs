## Proposing a change

A decision change is a change to its normative source, not an edit to this
documentation. Open the discussion in the owning repository, land the decision
there, and then update the documentation pages in the same change that updates
the artifacts — with the evidence packet the
[conformance](/docs/automations/conformance) rules require.
